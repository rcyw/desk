## 模型与科研

### 英伟达公开文档解析数据和微调配方

北京时间 13:05，英伟达在 Hugging Face 公布 Nemotron 3.5 Parse 后续材料。三套合成训练数据分别包含 998 万份图表样例、100 万份表格样例和 790 万份多语种文字识别样例，附图像、标注和生成说明。配方先用监督微调教模型把页面转为结构化记录，再用可验证奖励检查图表数值、表格结构和输出是否完整。做报表抽取或扫描件检索的团队，可以用自己的文档样例和校验规则适配这一流程。 [英伟达技术说明](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin)

厂商也披露了此前已加入模型仓库的 DFlash2 的吞吐测试。它先用小模型起草多个 token，再由主模型一起验证。在单张 H200、BF16 精度、同一批 2,078 页的单轮解析中，相较关闭推测解码，吞吐在并发 1 时为 7.62 倍，在并发 512 时为 1.52 倍。这组数据说明收益随负载而变。包含多轮重读或版面校验的生产流程，还需用实际文档量测吞吐与抽取准确率。 [DFlash2 仓库提交](https://huggingface.co/nvidia/Nemotron-3.5-Parse/commit/9f6ac6e314eab891125dfb0e6886da49d1dbaa09) · [测试条件与数据](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin#faster-inference-through-architecture-and-dflash2)

### OpenAI 开始小范围测试机密推理

北京时间 01:12，Sam Altman 表示 OpenAI 正与一小批客户测试 Private Inference。产品页将其标为 API 预览，称通过机密计算和访问控制保护模型处理中的提示和回复。零数据保留则约定合格的 API 工作流在处理后不留存提示和回复。对有敏感文档的企业，这两项措施覆盖数据生命周期中的不同阶段。公开材料尚未披露全面开放日期和详细的验证范围。 [Altman 发布帖](https://x.com/sama/status/2125638790593274259) · [OpenAI 产品说明](https://openai.com/business/private-intelligence/)

### 机器人仿真数据与推理研究

- **RoboUniverse 公开机器人仿真数据和权重。** Einsia 于北京时间 20:51 在 Hugging Face 发布仿真环境数据，23:21 上架 35B-A3B 权重。项目由视频重建了 10,807 个仿真环境。在发布方留出的 500 个仿真任务中，微调模型的成功率为 21.2%，底座 Qwen3.6-35B-A3B 为 0.8%。公开材料可供研究者复测，实机证据来自一次演示。 [项目页与评测](https://lab.einsia.ai/robo-universe/index.html) · [数据发布](https://huggingface.co/datasets/Einsia/RoboUniverse-10K/commit/0775b4832b70997eb9b138072566cff5d13b254a) · [权重发布](https://huggingface.co/Einsia/RoboUniverse-35B-A3B/commit/c62098b3c2b7dc53648ecb1072f5af85083348ef)
- **Ramp Labs 与 Base Labs 测试跨模型复用长文档缓存。** 团队于北京时间 00:27 发帖介绍 Speculative Encoding。它将来源模型处理文档时的内部状态转换成目标模型可用的键值缓存，实验覆盖七个模型之间的 42 个有向组合。团队报告，在 8,000 token 内保留了原生方式 96.9% 的准确率，在 32,000 token 的文档实验中，首 token 等待时间缩短至重读的约四分之一，并保留超过 90% 的准确率。 [技术报告](https://labs.baseten.co/articles/speculative-encoding-many-to-many-cache-translation) · [研究代码](https://github.com/b10-tv/speculative-encoding) · [发布帖](https://x.com/RampLabs/status/2125627502802653330)

## Agent 工程与开源

### Qwen Code 保留等待中的会话

北京时间 13:51，Qwen Code 发布 v0.28.6。托管会话在等待可恢复的工具审批、用户回答或后台任务时可以暂停。运行会话的 Harness 崩溃后，新进程可从保存的状态续接符合条件的等待。此前，一笔迟迟未获批准的工具调用可能长期占用运行进程，进程回收时也可能结束这次等待。新版把批准提示和等待状态保留下来，负责人可以稍后继续处理原来的请求。 [Qwen Code 版本说明](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.6) · [审批暂停的实现记录](https://github.com/QwenLM/qwen-code/pull/18115)

对需要人工批准写入或长期等待后台结果的任务，这降低了会话进程必须一直存活的要求。项目的恢复测试具体覆盖审批、拒绝、取消、超时与控制平面重启等场景，能否恢复仍取决于任务是否到了支持保存的等待点。无界面模式和 Ink 终端界面也在这一版默认切到基于事件总线的运行内核。 [Qwen Code 版本说明](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.6) · [审批恢复测试](https://github.com/QwenLM/qwen-code/pull/18276)

### Anthropic 用旧服务核验 Rust 迁移

北京时间 00:26，Anthropic 发帖公布 Messages API 从 Python 迁到 Rust 的复盘，实际迁移在 9 月。迁移团队让两版服务处理同一批线上流量，并复用同一份模型输出，避免把模型采样差异误判成 API 行为差异。集成测试通过率曾达到 98%，但 4 月影子比对开始时只有 24% 的输入匹配，至 8 月达到 99.6%。这给使用编程 Agent 重写在线服务的团队提供了一个做法，把旧服务输出纳入新版本验收。公司报告，迁移后单个区域的每请求 CPU 用量降约 70%，Claude Code 客户请求的首 token 延迟中位数降约 20%。 [Anthropic 发布帖](https://x.com/AnthropicAI/status/2125627317263466739) · [迁移复盘](https://www.anthropic.com/research/migrating-api-to-rust)

## 公司与算力

### 东南亚数据中心重新评估交付与融资

北京时间 13:00，《金融时报》援引知情人士报道，英伟达要求制造伙伴暂停向马来西亚、新加坡、泰国和印度尼西亚交付装有其芯片的服务器，部分买家收到订单无法发货的通知。英伟达拒绝向《金融时报》置评，涉及哪些型号、何时下达及暂停要持续多久均待确认。美国商务部 11 月 19 日生效的临时最终规则为背景。规则对这四国及巴西的特定先进计算产品增设许可要求，并对规定条件下的数据中心远程算力用途另设限制。 [《金融时报》原创报道](https://www.ft.com/content/7838a715-07d4-4605-aa60-21f5af2b2370) · [授权转载](https://www.channelnewsasia.com/asia/nvidia-halts-chip-shipments-southeast-asia-6584351) · [美国联邦公报](https://www.federalregister.gov/documents/2026/11/19/2026-23529/addressing-remote-access-to-advanced-semiconductors)

### FCC 为轨道算力设定分期部署条件

FCC 授权文件标注华盛顿当地 11 月 25 日，主席 Brendan Carr 于北京时间 26 日 00:09 公布决定。SpaceX 获准有条件部署以在轨计算为目标的 Starmind 星座，最多 100 万颗。按决定，首颗须最晚于 2033 年 11 月 25 日按许可条件投入运行，2035 年和 2038 年的部署门槛分别为 10% 和 50%，2040 年须完成部署。FCC 的射频授权限于备份和应急通信，高于 600 公里的部署还需提交许可修改申请和最终碎片缓解方案。可用算力仍取决于实际发射、在轨运行和地面数据传输。 [FCC 授权决定](https://docs.fcc.gov/public/attachments/DA-26-1273A1.pdf) · [Carr 发布帖](https://x.com/BrendanCarrFCC/status/2125623026918002860) · [AP 原创报道](https://apnews.com/article/spacex-data-center-elon-musk-b9897fe06f851ffaf92fd304ae69075c)

- **公开裁判文书记录了未披露的 AI 使用。** 《卫报》于北京时间 18:00 刊出调查，基于英国调查新闻局对公开裁判文书的梳理，英格兰和威尔士今年至少有 25 宗案件受到未披露的 AI 使用影响。案例涉及虚构判例和用 AI 起草证词，增加了来历和法律依据的核查工作。这个数字是调查找到的案例数，公开文书的覆盖范围限制了总体发生率的判断。 [调查新闻局原文](https://www.thebureauinvestigates.com/stories/2026-11-26/ai-is-throwing-the-court-system-into-disarray) · [《卫报》报道](https://www.theguardian.com/technology/2026/nov/26/dozens-of-court-cases-in-england-and-wales-affected-by-undisclosed-ai-use-in-2026)
