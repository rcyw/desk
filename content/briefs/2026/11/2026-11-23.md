## 模型与科研

### 智谱把循环 Transformer 带入旗舰编码模型

23 日中午，智谱 GLM Coding Plan 开始提供 GLM-5.4，晚间发布技术说明。开发文档列出文本和图像输入，订阅用户可让同一个编码模型读取界面截图或设计稿，再修改代码。公告也列出 ZCode 和 Z.ai Chat，通用 API 标为即将推出，开放权重仍是计划。 [上线消息](https://x.com/ZixuanLi_/status/2124719275864670681) · [智谱技术说明](https://z.ai/blog/glm-5.4) · [开发文档](https://docs.z.ai/devpack/latest-model)

GLM-5.4 在模型内部重复执行一组共享的网络层，用更多计算换取更深的处理过程。共享权重可减少增加层深时新增的参数，重复计算仍占用推理时间。智谱展示了用代码完成视频、CAD 和游戏的案例，并报告模型有时会陷入很长的思考循环。对已经使用 GLM-5.3 的团队，同一批任务的完成率、推理用时和订阅消耗更能检验这次升级。现有案例和对比来自智谱。 [智谱技术说明](https://z.ai/blog/glm-5.4)

### OpenAI 公开预训练损失并倡议共同设定推进条件

北京时间 01:03，OpenAI 首席科学家 Jakub Pachocki 分享官网标为 22 日的文章。文中公开自 GPT-3.5 起在同一内部代码保留集上测得的对数困惑度，也叫交叉熵损失。数值越低，表示模型平均越能预测下一个 token。文章给出的 GPT-3.5 和 GPT-4 约为 0.99 和 0.91，近期模型降到 0.8 以下。固定数据集让同一实验室可以比较多代基础模型的预训练进展。 [Pachocki 原帖](https://x.com/merettm/status/2124549218995949967) · [OpenAI 原文](https://openai.com/index/perplexity-and-intelligence/)

Pachocki 建议开发者用困惑度和其他测量预先约定推进界线，达到可检验的行为监测里程碑后再继续。08:37，微软 AI CEO Mustafa Suleyman 支持共用保留集，并称经 OpenAI 许可，MAI-2 Base 用同一数据集和分词器测得 0.819。这是两家在特许访问条件下的一次比较。对其他研究团队，获取相同测试集和对齐口径仍是前提。该分数只衡量预训练模型对这批代码的预测，任务成功率需要另测。共同界线与监测标准也仍待商定。 [OpenAI 原文](https://openai.com/index/perplexity-and-intelligence/) · [Suleyman 原帖](https://x.com/mustafasuleyman/status/2124663594449318173)

### 蚂蚁百灵开放通用多模态模型 Ling-3.2-air

23:42，蚂蚁百灵宣布开放 Ling-3.2-air 权重，采用 MIT 许可。模型约有 1,240 亿总参数，每个 token 激活约 55 亿，支持图像和视频输入。团队在测试中报告了更高的多步办公自动化成功率，法律基准加入重大幻觉检查后，全项通过率为 0.8%。团队考虑在文档流程中自部署时，可以用模型卡和评测材料检查各任务的错误分布。SGLang 于 23:51 合并部署指南，主线模型支持在当天仍有独立 PR 待审。 [百灵公告](https://x.com/AntLingAGI/status/2124891223597240338) · [模型卡](https://huggingface.co/inclusionAI/Ling-3.2-air) · [SGLang 部署指南 PR](https://github.com/sgl-project/sglang/pull/52598) · [模型支持 PR](https://github.com/sgl-project/sglang/pull/52593)

### 黎曼猜想的形式化证明通过一轮端到端核对

继 22 日刊所述的独立重建后，MIT 数学家 Andrew Sutherland 的日志记录，23 日 12:29，调整内存分配设置的一轮 Lean 严格内核核对接受了完整证明导出。17:10，Comparator v4.33.0 完成约 64 小时的一轮核对，用此前编译的文件和仓库配置通过了命题比对、公理检查以及 nanoda 和 Lean 默认内核验证。22:35 的日志仍把使用标准挑战导出文件的 v4.36.0 核对列为进行中。 [22 日刊](/brief/2026-11-22/) · [Sutherland 的复核记录](https://math.mit.edu/~drew/grh/) · [v4.33.0 运行日志](https://math.mit.edu/~drew/grh/comparator-v4.33.0.log)

### cmHC 预印本测试更省计算的残差流混合

中国电信星辰、港科大（广州）、哈工大（深圳）和华为团队的 cmHC 预印本进入 23 日 arXiv 公告。方法沿用 mHC 对混合矩阵的约束，改变多条残差流之间混合的范围。论文报告，在昇腾 910C 的部分测试配置下，超连接算子的前向和反向合计用时最多降低 44.8%。结果只计该算子的耗时，实际训练收益还取决于 Transformer 其他子层以及集群配置。 [arXiv 预印本](https://arxiv.org/html/2611.27193v1) · [作者代码](https://github.com/Newiz430/cmHC)

## Agent 工程

### OpenCode 把桌面浏览和定时任务接入工作区

17:22 发布的 OpenCode 2.4.0 新增桌面内置浏览器。浏览器可导入部分现有登录与历史，保留标签页，用户与 Agent 可在同一浏览器环境中查看和操作页面。自动化支持计时器、cron 和 MCP 事件触发。对于需要先登录后台再复现界面问题的团队，当前页面可以直接交给 Agent，也需要考虑共享配置里已有的账户会话。23:57 发布的 2.4.1 修复了 macOS 12 保存助手消息的问题，并恢复仅通过配置添加的 Ollama 等提供商的模型列表。 [2.4.0 发布说明](https://github.com/anomalyco/opencode/releases/tag/v2.4.0) · [2.4.1 发布说明](https://github.com/anomalyco/opencode/releases/tag/v2.4.1)

### OpenClaw 改善网关重启后的恢复

09:33 发布的 OpenClaw 2026.11.7 稳定版加入对部分中断回复和子任务结果的恢复，自动化记录也区分执行失败、跳过和恢复。运行定时 Agent 的团队遇到网关重启时，可以先查看任务状态，减少把已经恢复的工作当成失败而重跑。 [OpenClaw 发布说明](https://github.com/openclaw/openclaw/releases/tag/v2026.11.7)

### Atlas Cloud 暂撤其在 OpenRouter 上的模型

继 OpenRouter 22 日通报推理服务商的数据处理问题后，Atlas Cloud 于 23 日表示，先前向 MiniMax 官方 API 转发的部分测试请求出现第三方访问迹象，普通用户请求是否被读取仍无法确认。Atlas Cloud 称已停止向该 API 转发，并主动暂撤其在 OpenRouter 上的全部模型，待测试通过后恢复。经聚合平台调用模型的团队需要区分模型名称、实际处理请求的服务商和服务商使用的上游。 [Atlas Cloud 通报](https://www.atlascloud.ai/blog/ai-updates/security-and-privacy-commitment) · [OpenRouter 通报](https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers/)

## 政策与治理

### 韩国拟细化 AI 开发使用个人信息的审批

韩国个人信息保护委员会于北京时间 09:00 发布施行令修订草案并启动征求意见，截止日为 2027 年 1 月 4 日。韩国 9 月公布的法律修正案定于 2027 年 3 月 9 日生效。按草案，开发方拟使用原先合法收集的个人信息，须说明匿名或假名处理仍无法满足开发需求、符合公共或社会利益并落实增强保护措施，再由委员会审议。涉及敏感信息、唯一识别信息、儿童、持续跟踪或可能重大影响权益的决定时，还须评估风险。对已有客户数据的开发团队，是否能用于新模型取决于用途、保护措施和审议结果。 [韩国个人信息保护委员会公告及附件](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=C010010000&nttId=12663)

### 联合国科学小组比较五种建设本地语言 AI 的路径

北京时间 08:00，联合国独立国际 AI 科学小组的能力建设专题简报解禁。简报按成本、所需数据和控制权比较五种路径，从购买现成服务到从头训练，并指出本地团队可以先建立本地语言测试集，找出通用模型在哪些任务上表现不足，为采购、适配或自建提供依据。长期成效的证据仍有限。北京时间 21:00，巴巴多斯的布里奇敦 AI 峰会开幕，联合国秘书长古特雷斯在致辞中倡议在独立监督下开展多边风险管理。 [科学小组简报](https://www.un.org/independent-international-scientific-panel-ai/sites/default/files/2026-11/Thematic%20Brief_AI%20Capacity-Building_22%20Nov%202026.pdf) · [峰会议程](https://bridgetownaisummit.bb/#agenda) · [联合国开幕记录](https://transcripts.un.org/en/asset/k1z/k1zsh6j0we)
