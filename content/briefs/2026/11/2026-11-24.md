## Agent 工程与产品

### Claude Ship 把修订与审批接进 GitHub PR

北京时间 24 日凌晨，Anthropic 推出面向 Claude Team 和 Enterprise 的 Claude Ship。原有 Code Review 负责找问题，新增的 PR Steward 进入测试，可处理 CI 失败、合并冲突和评审反馈，提交修订并说明改了什么。另一项测试功能 Claude Approvals 读取团队存放在仓库里的审批策略，对满足条件的变更给出批准，其余按策略交给人工。路透在北京时间 04:05 报道了这次发布。 [Anthropic 公告](https://claude.com/resources/articles/introducing-claude-ship) · [路透报道](https://www.investing.com/news/stock-market-news/anthropic-launches-claude-ship-to-help-developers-ship-code-faster-5046300)

对维护者，变化在于一次代码审查可以接上后续修订和审批。团队可以先让 Approvals 只观察，把它的判断与人工结果比较，再决定哪些变更可以接受自动批准。最终能否合并仍取决于 GitHub 的分支规则与权限，例如仓库要求代码所有者审阅时，仍要取得该审阅。Anthropic 展示了自己的内部使用案例，外部团队还需观察它在各自仓库里的误批与返工情况。 [Anthropic 的流程、仓库设置与内部案例](https://claude.com/resources/articles/introducing-claude-ship)

### Agent 会话和待审批操作开始一起恢复

- **Codex 0.172.0** 于北京时间 08:03 发布。终端可以从搜索结果和会话记录里的链接重开已保存的会话或子 Agent，`codex exec resume` 在未显式覆盖时恢复原有沙箱权限、工作目录和工作区根。对继续前一班次的任务，这能保留当时的执行环境。 [Codex 发布说明](https://github.com/openai/codex/releases/tag/rust-v0.172.0)
- **OpenAI Agents SDK Python 1.0.0-alpha.2** 于北京时间 04:11 在 GitHub 发布预览，可用 Responses 或 Codex 跨工作进程恢复会话和待审批操作。原生 Codex 命令或编辑审批能否恢复受本地环境、工作区和策略限制，旧版 alpha.1 也读不了新版快照。 [Agents SDK 预览说明](https://github.com/openai/openai-agents-python/releases/tag/v1.0.0-alpha.2)
- **火山引擎 OpenViking 0.5.6** 于北京时间 12:16 发布。多节点部署可用 PostgreSQL 共用账户、任务和监视状态，后台队列在重试和恢复时保留原消息及顺序。已有部署切换存储时须预先建表并迁移存量数据，Compile 接口也有破坏性变更。 [OpenViking 发布与迁移说明](https://github.com/volcengine/OpenViking/releases/tag/v0.5.6)

## 模型、开放权重与科研

### 百度开放文心 5.5 Flash Preview 权重

百度在 11 月 11 日公布预览模型时先提供千帆 API，北京时间 24 日宣布开放权重。模型卡列出 2,800 亿总参数、每 token 激活 140 亿的混合专家架构，支持约 100 万 token 上下文，输入输出均为文本。默认权重混用 FP8 和 FP4，另有 FP8 和 BF16 版本。Apache 2.0 覆盖这次公布的 Preview 权重，早先的 Base 仍适用自己的许可。 [百度首发公告](https://ernie.baidu.com/zh/release/ernie-5-5-flash-preview/) · [百度官方发布帖](https://x.com/Baidu_Inc/status/2125077484442190137) · [模型卡与权重](https://huggingface.co/baidu/ERNIE-5.5-Flash-Preview)

对需要在自己的硬件上部署或微调的团队，权重开放后可以直接比较三种精度的显存、吞吐和效果。每 token 激活的参数量主要描述计算用量，部署仍需为整套专家权重和长上下文缓存留出空间。模型卡上的成绩来自发布方自测，百度也注明这仍是后训练进行中的检查点。 [模型评测与部署说明](https://huggingface.co/baidu/ERNIE-5.5-Flash-Preview)

### 腾讯混元翻译扩到 102 种语言

腾讯在北京时间 24 日下午开放 Hy-MT3 的 1.8B、7B 和 30B-A3B 权重，并发布自动评测工具 TransRubric。前代覆盖 38 种语言。团队称在自己的真实场景测试集上，误译样本比例相对下降 43%，漏译或增译样本比例相对下降 74%。对游戏本地化团队，新增的测试涉及术语、富文本和占位符等约束。自动分数仍需结合目标语言和实际素材复测。 [腾讯发布记录](https://github.com/Tencent-Hunyuan/Hy-MT3) · [技术报告 v2](https://arxiv.org/abs/2611.27673v2) · [IT之家当日报道](https://www.ithome.com/1/031/681.htm)

### GPT-6.2 Sol 的对话版本进入 ChatGPT 聊天页

OpenAI 于北京时间 24 日凌晨宣布向 Plus、Pro、Business 和 Enterprise 逐步推出面向聊天调优的 GPT-6.2 Sol。此前的 17 日发布已覆盖 API 等渠道。OpenAI 报告聊天页图像理解测试从 GPT-6 的 47.4% 升到 71.7%，对应其内部测试。对已有的图像问答和复杂指令，用户可以用自己的输入核对这一变化。 [ChatGPT 发布说明](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) · [官方发布帖](https://x.com/ChatGPT/status/2124942186425069836) · [11 月 17 日发布公告](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

### Gemini Agent 提议量子算法，Lean 复核改进

北京时间 01:00，Google DeepMind 与 Google Quantum AI 介绍了用多组 Gemini 4 Agent 改写量子算法的研究，并链接开放的 Lean 4 库、问题规范和可核对的解。相关预印本较早已公开。团队先为各组设定同一问题，候选方案通过 Lean 检查后才进入共享笔记，Agent 定期比较各组进展。对同一个惯性约束聚变模拟子问题，论文团队报告综合量子比特和操作数的资源成本降至原先约 1/11.8，所需纠错量子比特从 5,650 减到 4,338。 [Google DeepMind 公告](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/) · [预印本 v3](https://arxiv.org/abs/2611.09822v3) · [Lean 4 库](https://github.com/google-deepmind/formal-quantum-computation)

研究者可以检查 Agent 生成的电路是否满足同一个形式化规范，并在同一资源度量下比较结果。Lean 提供的是对规范和模型内资源估计的数学保证。这些大电路仍超出现有小型量子处理器的运行能力，实际硬件上的运行时间和误差要等后续实验。 [Google DeepMind 的实验与限制](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)

## 政策与治理

### 美国出口管制实体清单增列七家东南亚实体

北京时间 05:15，美国联邦公报开放查阅美国商务部工业与安全局的待刊最终规则。规则增列七家实体，分别列在马来西亚、新加坡和泰国项下，其中三家的名称含 Megaspeed。规则援引先进计算物项可能被转给未经授权的最终用户或用途的风险，对涉及所列实体、受美国《出口管理条例》管辖的物项规定许可要求，审查原则上推定拒绝。文本指定公开查阅日生效，正式刊登排在美国当地 11 月 25 日。涉及这些客户的出口、再出口和境内转移需按新规则核对。 [联邦公报待刊记录](https://www.federalregister.gov/public-inspection/2026-23999/additions-to-the-entity-list) · [规则原文](https://public-inspection.federalregister.gov/2026-23999.pdf)

### 布里奇敦峰会呼吁拟定多边 AI 风险框架

巴巴多斯政府与联合国共同主办的峰会在北京时间 24 日凌晨闭幕，巴巴多斯总理莫特利与联合国秘书长古特雷斯发布行动呼吁，倡议在一年内拟定多边 AI 风险管理框架，设置可信的独立监督，并扩大发展中国家的评估和治理能力。拟议的全球 AI 能力建设基金寻求约 30 亿美元初期承诺，后续取决于各方出资和框架谈判。 [峰会议程](https://bridgetownaisummit.bb/) · [闭幕公告](https://bridgetownaisummit.bb/wp-content/uploads/2026/11/PRESS-RELEASE-Bridgetown-Special-Summit-on-AI-Safety.pdf)

### 市场监管总局介绍生成式 AI 和推理服务国际标准工作

市场监管总局于北京时间 24 日上午召开专题发布会，17:00 发布实录。会上介绍中国牵头推动的生成式 AI 系统风险指南，以及涵盖输入、推理服务、输出和基础设施四个环节的大模型推理服务安全提案。前者在 ISO 项目页仍处于审批阶段。对提供推理服务或承担评测的团队，这两项工作分别涉及生成式系统的生命周期风险和推理环节的安全评估。 [市场监管总局发布会实录](https://www.samr.gov.cn/xw/xwfbt/art/2026/art_7aa3b165c4114ac1ac910a34f8fca79e.html) · [ISO/IEC DTS 25568](https://www.iso.org/standard/90754.html)
