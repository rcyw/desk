## 推理服务与数据治理

### OpenRouter 撤下 125 个端点的零留存资格

OpenRouter 22 日通报，安全研究人员在部分上游推理服务商发现数据泄露或未按政策处理数据的迹象。平台下架了三家服务商，撤下 125 个端点的零数据留存（ZDR）资格，其中一部分是预防性撤下，并称已通知可能受影响的客户。OpenRouter 称调查未发现其平台本身遭入侵的迹象，正在核验上游是否将请求转给第三方。 [OpenRouter 通报](https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers/)

Novita 同日确认，部分 MiniMax 推理请求被转至 MiniMax 的官方 API，已暂停受影响的模型，第三方的数据留存或访问情况仍在调查。Together AI 的单独通报确认，6 至 7 月的一部分无服务器推理提示词样本曾被未获授权的一方下载。通过聚合平台调用同一个模型时，数据处理承诺还取决于实际承接请求的端点。 [Novita 通报](https://novita.ai/blog/minimax-requests-privacy-notice/) · [Together AI 事件说明](https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026)

## 科研与独立验证

### 黎曼猜想的复核延伸到约数和不等式

继 21 日 Lean 与 Mathlib 社区发布联合声明后，MIT 数学家 Andrew Sutherland 的复核日志记录了 22 日凌晨完成的一次沙箱重建。独立机器从归档重新编译，生成的证明导出文件与原文件逐字节一致。北京时间 07:02，独立检查器 con-ron 核对通过五条目标定理，其中包括经典黎曼猜想和 Dirichlet L 函数版本的广义黎曼猜想。 [21 日刊](/brief/2026-11-21/) · [Sutherland 的复核日志](https://math.mit.edu/~drew/grh/)

Sutherland 还把这份 Lean 证明与 Robin1984 项目独立形式化的等价判据结合，得到 Robin 和 Lagarias 的两条约数和不等式，让检查可以落到不含 ζ 函数的算术命题上。con-ron 核对通过两条命题，nanoda 于北京时间 10:56 通过合并后的完整证明导出文件。日志中的 `lake comparator` 端到端复核仍在运行。 [算术推论与检查记录](https://math.mit.edu/~drew/grh/#arithmetic-consequences)

## 模型与行业应用

### 蚂蚁百灵公布开放权重医疗模型

北京时间 22 日 23:22，蚂蚁百灵官方账号公布 LingSante-3.1-flash。此前已上传的模型权重采用 MIT 许可，另有当天公开的 MXFP4 量化版本。模型为混合专家架构，总参数约 5,600 亿，每个 token 激活约 250 亿，上下文上限为 100 万 token。团队把医疗推理、证据核验和多步任务纳入同一模型，并把用途限定为研究和评测。模型卡列出的结果来自团队评估，临床适用性仍需独立验证。 [团队原帖](https://x.com/AntLingAGI/status/2124523916819648945) · [模型卡](https://huggingface.co/inclusionAI/LingSante-3.1-flash) · [MXFP4 权重](https://huggingface.co/inclusionAI/LingSante-3.1-flash-MXFP4)

### Sarvam 更新 105B API 的默认权重

北京时间 22 日 23:55，Sarvam 公布 Sarvam-105B-1711，同日 API 日志记录两个现有模型 ID 已切换至新权重，请求格式沿用原接口。该版本面向高频客服、语音 Agent 和印度语言对话。按厂商的八项对话 Agent 评测，量化版平均分从前代的 42.6 升至 73.9。以输入和输出 token 为 3:1 计算，厂商列出的混合单价从每百万 token 0.44 美元降至 0.15 美元。对已经接入这两个模型 ID 的团队，业务回归测试尤其值得关注多轮指令遵循和工具调用。 [团队原帖](https://x.com/SarvamAI/status/2124532170505273661) · [评测与价格口径](https://www.sarvam.ai/blogs/sarvam-105b-1711) · [API 更新日志](https://docs.sarvam.ai/changelog/2026/11/22)

### 海洋多模态模型「文鳐」进入场景验证

据人民网 22 日现场报道，厦门理工学院联合哈尔滨工程大学、众数文鳐等团队在厦门发布新一代「文鳐」。团队称模型能综合解读多类装备数据并动态调整作业任务，相关功能已进入场景验证。试用中的「AI 轮机长」可以结合设备数据与图纸、手册，把故障诊断和排查建议发给船上的轮机长。远海通信受限，这类试用能观察模型能否及时给出建议，以及哪些情况仍须人工处置。 [人民网现场报道](http://fj.people.com.cn/n2/2026/1122/c181466-41757641.html)

## 开源与 Agent 工程

### Browser Use 把任务评判接到原运行末尾

Browser Use 于北京时间 22 日 11:30 发布 1.0.8。新版默认把判断任务是否成功的请求接为原会话的下一轮，让支持提示词缓存的供应商有机会复用前文，评判结果仍沿用原字段。版本也加入了防止密码输入值出现在工具输出中的处理。能节省多少评判开销，取决于实际使用的供应商和缓存命中率。 [1.0.8 发布说明](https://github.com/browser-use/browser-use/releases/tag/1.0.8) · [评判实现变更](https://github.com/browser-use/browser-use/pull/6457)

### vLLM 与 SGLang 分别处理缓存写入和传输

vLLM 于北京时间 22 日 14:20 合入修复。长请求的键值缓存（KV 缓存）超出 CPU 缓存层可用容量时，现在先写入放得下的块，再在后续步骤重试剩余块。SGLang 于 17:43 将预填充与解码之间的 KV 缓存传输接入统一接口。贡献者在模拟传输引擎、每层 2,048 个页面组的测试里，观察到 CPU 构建传输计划的中位用时从 46 毫秒降至 10 毫秒。同一 PR 报告的双 H100 端到端吞吐量持平。 [vLLM 合入记录](https://github.com/vllm-project/vllm/pull/66719) · [SGLang 合入记录](https://github.com/sgl-project/sglang/pull/46460)
