# Wayne’s Desk

[English](README.md)

Desk 是用 Astro 构建的 Platinum9 风格网页桌面，默认打开 **Wayne’s Notes**。博客的文章和专题来自仓库里的 Markdown。

[打开 Desk](https://rcyw.github.io/)

可从浏览器菜单安装 Desk。iPhone 或 iPad 在 Safari 的分享菜单中选择「添加到主屏幕」，并开启「作为 Web App 打开」。

## 写作

文章和配图放在 `content/posts/<slug>/`，专题放在 `content/topics/`。 [内容工作流](docs/content-workflow.md)

开发与验证命令集中在英文 README。 [本地开发](README.md#local-development) · [验证](README.md#verification)
