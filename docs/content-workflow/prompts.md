# Prompts 模板

把同一使用场景的模板放在 `content/prompts/<slug>.md`，直链为 `/prompts/<slug>/`。同一场景优先更新原文，适合单独分享或长期独立维护的模板才另建一篇。

每个独立用途用二级标题和一个顶层 `text` 围栏。围栏里的文字会被复制，应保留原提示词的使用时机、动作、交付物和默认条件，只在确有需要时加参数。说明、可调项和出处放在围栏外，在 `sources` 记录原始出处。

所附英文版可放进 `<details class="prompt-language" lang="en">`，用 `<summary>English</summary>` 和单独的 `text` 围栏提供独立复制。本地预览时逐一点击 `Copy Prompt`，核对每个按钮复制出的提示词。
