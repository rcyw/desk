# Papers 论文读解

## 稿件与论文版本

论文读解放在 `content/papers/<slug>.md`，直链为 `/papers/<slug>/`。先按论文原题、arXiv ID 或 DOI 查找旧稿。重读同一篇论文有新收获时，把结论和所读版本补进原笔记，有实质更新时填写 `updatedAt`。

配图放在文章旁的 `./assets/<slug>/`，用相对路径引用。用 `topics` 引用至少一个 `content/blog/topics/` 中已建的专题。[维护专题](../content-workflow.md#维护专题)

| 字段            | 填写内容                     |
| --------------- | ---------------------------- |
| `title`         | 这篇读解的标题               |
| `paper.title`   | 论文原题                     |
| `paper.source`  | 会议、期刊或预印本平台       |
| `paper.url`     | 所读版本的原文链接           |
| `paper.version` | 原文版本号或可核对的公开日期 |

原文有可定位的版本号时，链接与编号须对应。例如阅读 arXiv 的 `v2`，就在 `paper.url` 链接该版本，并在 `paper.version` 填写 `v2`。

## 成稿

从一个具体问题切入，交代论文要回答什么以及作者的主要主张。先解释理解方法所需的概念和假设，再用案例逐步解释核心设计和结果，指出证据来自哪些实验、图表或段落。最后讨论结论成立的条件、局限和应用场景，标清作者结论、自己的判断与已复现的结果。有助于理解时，用 Mermaid 展示关键机制。
